# Appscrip Task - Product Listing Page

This project is a product listing page built with Next.js, React, and CSS Modules. It uses the Fake Store API to fetch product data and implements server-side rendering for optimal performance and SEO.

## Features

- Responsive design for mobile, tablet, and desktop
- Server-side rendering with Next.js
- Product filtering by category, price range, and rating
- Product sorting by price, rating, and name
- SEO optimization with meta tags and structured data
- Minimal DOM size and optimized code structure
- Clean and maintainable code with proper naming conventions

## Technologies Used

- Next.js 13
- React 18
- CSS Modules
- Axios for API requests
- Fake Store API
